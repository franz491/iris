Read and modify files inside a sandboxed folder. Paths are relative to that folder. Read a file before changing it; use line numbers before `edit_lines`. `create_file` replaces an entire file, `edit_file` replaces one exact block, and `search_and_replace` changes every regex match. The local version must be enabled with an allowed folder in the target user's tool settings. Never assume access to files outside that folder. Backend shell shares this writable root at `/sandbox`; documentation is available read-only at `/sandbox/docs`. If you have access to a backend and frontend version of this tool, only use the backend one when explicitly asked to.
